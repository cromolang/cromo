Install Cromo @VERSION@

One line installs cromo, its library and the extension for VS Code, for your user and without administrator rights, in ~/.cromo. The script checks the SHA-256 of the archive against the manifest of the version, and adds cromo to the PATH.

Windows x64 your system

In PowerShell:

> irm https://cromolang.org/install.ps1 | iex

64-bit Windows. Or download the archive: win_x86_64-@VERSION@.zip, @WIN_SIZE@.

Linux x64 your system

In a terminal:

$ curl -sSf https://cromolang.org/install.sh | sh

Linux on x86-64 with glibc 2.29 or later, as Ubuntu 20.04 and later, and curl, tar and sha256sum. Or download the archive: linux_x86_64-@VERSION@.tar.gz, @LINUX_SIZE@.

then, in a new terminal
$ cromo version
cromo @VERSION@ (LLVM 23.1.4)
$ cromo run hello.cro
Hello, world!
Archives

Version @VERSION@

Each archive holds cromo in bin, the library and the runtime in lib, the extension for VS Code in extension, and the licenses. The manifest of the version lists the archives with their SHA-256; cromo update checks its Ed25519 signature before it installs a version.

SystemArchiveSizeSHA-256
Windows x64win_x86_64-@VERSION@.zip@WIN_SIZE@@WIN_SHA256@
Linux x64linux_x86_64-@VERSION@.tar.gz@LINUX_SIZE@@LINUX_SHA256@

The manifest: release/@VERSION@, and its signature: release/@VERSION@.sig. The latest version is always at cromolang.org/latest.

More

After the installation

Updating

cromo update installs the latest version next to the one you have, after checking its signature, and makes it the active one. cromo update 0.27.1 goes back to an older version.

Linux on ARM64

cromo runs on Windows x64 and Linux x64, and both write programs for Linux on ARM64, as a Raspberry Pi or a server with Graviton: cromo build --target linux-arm64. A cromo that runs on ARM64, Windows on ARM64 and macOS come later.

Installing by hand

Unpack the archive anywhere and add its bin folder to the PATH: cromo finds its library in lib, next to bin. The extension is the .vsix file in extension.

Visual Studio Code

The installer adds the extension when it finds the command code. It is also cromolang.cromo in the Visual Studio Marketplace and in Open VSX.

Uninstalling

Delete ~/.cromo, %USERPROFILE%\.cromo on Windows, and its bin from the PATH: on Windows the installer added it to the PATH of the user, on Linux to ~/.profile, ~/.bashrc and ~/.zshrc, after the line # Cromo.

The guide and the sources

The Cromo Guide, also as PDF, in English and in Italian. The compiler, the library and the design decisions are on GitHub, with the way to build them.

Cromo is the Italian name of element 24 of the periodic table.
